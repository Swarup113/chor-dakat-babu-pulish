Roles:
    Babu: Immune player, always gets 100 points
    Pulish: The guesser - must find the culprit (Chor or Dakat)
    Chor: Thief - target in Chor rounds, gets 40 points if escapes
    Dakat: Bandit - target in Dakat rounds, gets 60 points if escapes

Round Types:
    Chor Round: Pulish must find the Chor
    Dakat Round: Pulish must find the Dakat
Rounds alternate: Chor → Dakat → Chor → Dakat...

Scoring:
    Babu: Always 100 points
    Pulish: 80 points if correct guess, 0 if wrong
    Target Culprit: 0 if caught, 40 (Chor) / 60 (Dakat) if escapes
    Non-target Culprit: Always immune - Chor gets 40, Dakat gets 60

How to Play:
    Each player secretly views their role by clicking their button
    After all players have viewed, Babu and Pulish are revealed
    Pulish has 30 seconds to guess who is the culprit
    Points are awarded based on the result
Game continues for 10 rounds or can be ended at any stages.
